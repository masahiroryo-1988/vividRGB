# Changelog

## 0.1.0 — 2026-10-06

- First installable vividRGB library and command-line workflow.
- Frozen DINOv3 adapter, custom dense-encoder interface and image-only SAM3 adapter.
- Local 5%/10% focus defaults, four-reflection averaging, approximately 75% overlap and Hann reconstruction.
- Centered unwhitened PCA, orthogonal varimax, automatic K-means and full-covariance GMM with lambda=4.
- Frozen research evidence, dependency-complete script snapshots and portable research paths.
- CPU tests, optional GPU equivalence validation, wheel/source builds and Trusted Publishing workflows.
